# 介绍

ZXUI CN 是一个基于 Vue 3 的现代化组件库，专注于提供优雅、直观且高性能的用户界面组件。

## 特性

### 🚀 现代化
- 基于 Vue 3 + TypeScript 开发
- 支持 Tree Shaking
- 支持按需引入
- 支持 SSR

### 🎨 可定制
- 提供丰富的主题变量
- 支持暗黑模式
- 支持自定义主题
- 支持组件级别样式覆盖

### 🌍 国际化
- 内置中文和英文支持
- 支持自定义语言包
- 支持动态切换语言
- 支持日期、数字等本地化

### 📦 组件丰富
- 包含 30+ 个常用组件
- 覆盖常见业务场景
- 持续更新和维护
- 高质量的代码实现

### 📚 文档完善
- 详细的 API 文档
- 丰富的示例代码
- 完整的类型定义
- 清晰的更新日志

### 🔧 开发友好
- 完整的 TypeScript 支持
- 友好的开发者工具
- 详细的错误提示
- 活跃的社区支持

## 安装

```bash
# 使用 pnpm
pnpm add zxui-cn

# 使用 npm
npm install zxui-cn

# 使用 yarn
yarn add zxui-cn
```

## 快速开始

```vue
<template>
  <z-button type="primary">主要按钮</z-button>
</template>

<script setup lang="ts">
// 使用自动按需引入时，无需手动导入组件
</script>
```
