# 更新日志

- 新增 `Select` 组件的远程搜索功能

- 新增 `Table` 组件的虚拟滚动功能

### 🐛 问题修复
- 修复 `Input` 组件在暗色主题下的边框颜色问题
- 修复 `Modal` 组件在多层嵌套时的遮罩层问题

- 优化组件库的 Tree Shaking 支持

## 版本规范

ZXUI CN 遵循 [Semantic Versioning 2.0.0](https://semver.org/lang/zh-CN/) 语义化版本规范：

- 主版本号：包含不兼容的 API 变更
- 次版本号：包含向下兼容的功能性新增
- 修订号：包含向下兼容的问题修复
