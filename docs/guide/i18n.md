# 国际化

ZXUI CN 组件库提供了国际化支持，默认使用中文。

## 配置方法

### 基础用法

```ts
import { createApp } from 'vue'
import ZXUI from 'zxui-cn'
import enUS from 'zxui-cn/locale/en-US'

const app = createApp(App)

app.use(ZXUI, {
  locale: enUS
})
```

### 按需引入

```ts
import { Button, Input } from 'zxui-cn'
import enUS from 'zxui-cn/locale/en-US'
import { setupI18n } from 'zxui-cn/locale'

// 设置语言
setupI18n(enUS)

// 使用组件
app.use(Button).use(Input)
```

## 支持的语言

目前支持以下语言：

- 简体中文（zh-CN）
- 英文（en-US）
- 繁体中文（zh-TW）
- 日文（ja-JP）

## 切换语言

可以通过调用 `setLocale` 方法动态切换语言：

```ts
import { setLocale } from 'zxui-cn/locale'
import enUS from 'zxui-cn/locale/en-US'

// 切换到英文
setLocale(enUS)
```

## 自定义语言包

你可以根据需要自定义或扩展语言包：

```ts
const myLang = {
  name: 'my-lang',
  el: {
    button: {
      submit: '提交',
      reset: '重置',
      // ... 其他按钮相关文案
    },
    input: {
      placeholder: '请输入',
      // ... 其他输入框相关文案
    }
    // ... 其他组件的文案
  }
}

// 使用自定义语言包
app.use(ZXUI, {
  locale: myLang
})
```

## 日期格式化

对于日期相关的组件，我们使用 Day.js 进行国际化处理：

```ts
import 'dayjs/locale/zh-cn'
import dayjs from 'dayjs'

// 设置 Day.js 的语言
dayjs.locale('zh-cn')
```

## 数字格式化

对于数字相关的组件，我们使用 Intl.NumberFormat 进行国际化处理：

```ts
const formatter = new Intl.NumberFormat('zh-CN', {
  style: 'currency',
  currency: 'CNY'
})

// 格式化数字
formatter.format(1234.56) // ¥1,234.56
```

## 最佳实践

### 配合 Vue I18n 使用

如果你的项目使用了 Vue I18n，可以这样配置：

```ts
import { createApp } from 'vue'
import { createI18n } from 'vue-i18n'
import ZXUI from 'zxui-cn'
import enUS from 'zxui-cn/locale/en-US'

const i18n = createI18n({
  locale: 'en-US',
  messages: {
    'en-US': {
      // 你的应用翻译
    }
  }
})

const app = createApp(App)
app.use(i18n)
app.use(ZXUI, {
  locale: enUS
})
