# 国际化

国际化（Internationalization，简称 i18n）是指设计和开发软件时考虑不同语言和地区的需求，使其能够适应各种语言和文化环境。ZXUI CN 提供了完善的国际化支持，可以轻松实现多语言切换。

## 基础国际化

基础的多语言切换示例，支持中文、英文和日文切换。

## 使用 vue-i18n

结合 vue-i18n 库实现更完善的国际化解决方案。这个示例展示了如何使用 vue-i18n 进行更高级的国际化处理，包括日期格式化、数字格式化和复数处理。

```vue
<template>
  <div class="vue-i18n-demo">
    <div class="language-switch">
      <zx-button-group>
        <zx-button 
          :type="locale === 'zh-CN' ? 'primary' : ''"
          @click="changeLocale('zh-CN')"
        >
          中文
        </zx-button>
        <zx-button 
          :type="locale === 'en-US' ? 'primary' : ''"
          @click="changeLocale('en-US')"
        >
          English
        </zx-button>
        <zx-button 
          :type="locale === 'ja-JP' ? 'primary' : ''"
          @click="changeLocale('ja-JP')"
        >
          日本語
        </zx-button>
      </zx-button-group>
    </div>
    
    <div class="demo-content">
      <zx-card :title="$t('dashboard.title')">
        <div class="dashboard">
          <div class="welcome-message">
            <h2>{{ $t('dashboard.welcome', { name: user.name }) }}</h2>
            <p>{{ $t('dashboard.lastLogin', { date: $d(user.lastLogin, 'long') }) }}</p>
          </div>
          
          <div class="statistics">
            <h3>{{ $t('dashboard.statistics') }}</h3>
            <div class="stat-cards">
              <zx-card class="stat-card">
                <div class="stat-value">{{ $n(stats.visitors) }}</div>
                <div class="stat-label">{{ $t('dashboard.visitors') }}</div>
              </zx-card>
              
              <zx-card class="stat-card">
                <div class="stat-value">{{ $n(stats.orders) }}</div>
                <div class="stat-label">{{ $t('dashboard.orders') }}</div>
              </zx-card>
              
              <zx-card class="stat-card">
                <div class="stat-value">{{ $n(stats.revenue, 'currency') }}</div>
                <div class="stat-label">{{ $t('dashboard.revenue') }}</div>
              </zx-card>
              
              <zx-card class="stat-card">
                <div class="stat-value">{{ $n(stats.growth, 'percent') }}</div>
                <div class="stat-label">{{ $t('dashboard.growth') }}</div>
              </zx-card>
            </div>
          </div>
          
          <div class="notifications">
            <h3>{{ $t('dashboard.notifications') }}</h3>
            <div class="notification-list">
              <zx-alert
                v-for="(notification, index) in notifications"
                :key="index"
                :title="notification.title"
                :type="notification.type"
                :description="notification.description"
                :closable="true"
                class="notification-item"
              />
              
              <div v-if="notifications.length === 0" class="no-notifications">
                {{ $t('dashboard.noNotifications') }}
              </div>
            </div>
          </div>
          
          <div class="activity">
            <h3>{{ $t('dashboard.recentActivity') }}</h3>
            <div class="activity-list">
              <div 
                v-for="(activity, index) in activities"
                :key="index"
                class="activity-item"
              >
                <div class="activity-time">{{ $d(activity.time, 'short') }}</div>
                <div class="activity-icon">
                  <zx-icon :name="activity.icon" />
                </div>
                <div class="activity-content">
                  <div v-if="activity.type === 'message'" class="activity-message">
                    {{ $t('activity.message', { user: activity.user }) }}
                  </div>
                  <div v-else-if="activity.type === 'order'" class="activity-order">
                    {{ $tc('activity.order', activity.count, { user: activity.user, count: activity.count }) }}
                  </div>
                  <div v-else-if="activity.type === 'system'" class="activity-system">
                    {{ $t('activity.system') }}
                  </div>
                  <div class="activity-description">{{ activity.description }}</div>
                </div>
              </div>
              
              <div v-if="activities.length === 0" class="no-activity">
                {{ $t('dashboard.noActivity') }}
              </div>
            </div>
          </div>
        </div>
      </zx-card>
    </div>
  </div>
</template>
